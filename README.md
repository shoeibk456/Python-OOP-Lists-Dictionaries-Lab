# Employee Management System
# Project Overview
The Employee Management System is a Python application developed using Object-Oriented Programming (OOP) concepts. The system allows users to manage employee records efficiently by adding, viewing, searching, updating, and deleting employee information. This project demonstrates the use of classes, methods, lists, dictionaries, user input handling, and data management techniques.

# Features
Add new employee records.
Display all employee records.
Search for an employee by name.
Update employee information.
Delete employee records.
Input validation for user entries.

# Logic Used
Python 
Object-Oriented Programming (OOP).
